INFORMAÇÕES SOBRE ESTE SITE

Privacidade & uso responsável

Um site informativo

Este site apresenta a Akasha e seus projetos públicos. Não inclui cadastro, checkout ou formulário de coleta. O código atual não usa ferramentas de analytics, publicidade, cookies próprios ou armazenamento local no navegador. Fontes e recursos visuais não exigem serviços externos.

Hospedagem e links externos

O site é hospedado no GitHub Pages. O provedor pode tratar dados técnicos de acesso conforme sua própria política. Ao abrir links para GitHub ou outros serviços, passam a valer as práticas desses serviços.

Contato por e-mail

Os links de contato abrem seu aplicativo de e-mail. Se você decidir enviar uma mensagem, os dados que incluir serão recebidos pelo canal de suporte da Akasha. Envie apenas o necessário para iniciar a conversa. Não inclua senhas, segredos, dados pessoais sensíveis ou detalhes de vulnerabilidades não divulgadas.

Uso responsável das ferramentas

Ferramentas de segurança devem ser utilizadas apenas em sistemas próprios ou com autorização. Consulte a licença, os requisitos, o estágio de desenvolvimento e as limitações de cada repositório. O conteúdo deste site não constitui garantia de resultado, certificação ou oferta contratual.

ABOUT THIS WEBSITE

Privacy & responsible use

An informational website

This website introduces Akasha and its public projects. It has no registration, checkout or data-collection form. The current code uses no analytics, advertising, first-party cookies or browser local storage. Fonts and visual assets require no external services.

Hosting and external links

This website is hosted on GitHub Pages. The hosting provider may process technical access data under its own policy. When you follow links to GitHub or other services, their own practices apply.

Email contact

Contact links open your email application. If you choose to send a message, the information you include will be received through Akasha’s support channel. Share only what is needed to start the conversation. Do not include passwords, secrets, sensitive personal data or details of undisclosed vulnerabilities.

Responsible use of tools

Security tools should only be used on systems you own or are authorized to test. Review each repository’s license, requirements, development stage and limitations. This website does not offer a guarantee of results, certification or contractual terms.
